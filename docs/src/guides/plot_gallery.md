# Plot gallery

Every chart below is built with the pure-Dune [`plot`](../stdlib/plot.md)
module and rendered to SVG with `plot.svg(chart)`. Each uses a helper that
samples a function across an interval:

```dn
import io;
import math;
import plot;

fn linspace(start: real64, stop: real64, n: int): [real64] {
    step = (stop - start) / ((n - 1) to real64);
    return [start + (i to real64) * step for i in 0..n];
}
```

Grids come from `.grid(cells)` (major divisions per axis) and
`.minor_grid(subdivisions)` (finer lines inside each cell).

## Sine wave

The canonical periodic curve. `linspace` builds the x samples and a comprehension maps `math.sin` over them; `grid(6).minor_grid(4)` adds a major grid with four minor divisions per cell.

```dn
xs = linspace(0.0, 12.566, 90);
ys: [real64] = [math.sin(xs[i]) for i in 0..xs.len()];
chart = plot.line(xs, ys)
    .title("y = sin(x)").x_label("x").y_label("amplitude")
    .grid(6).minor_grid(4).size(560, 320);

io.println(plot.svg(chart).contains("<svg")); // 1
```

## Damped oscillation

xs = linspace(0.0, 18.0, 120);
ys: [real64] = [math.exp(-xs[i] / 6.0) * math.sin(2.0 * xs[i]) for i in 0..xs.len()];
chart = plot.line(xs, ys).title("Damped oscillation").grid(6).minor_grid(5);

io.println(plot.svg(chart).contains("<svg")); // 1

## Subplots

`plot.subplots(charts, cols)` arranges several charts into one figure as a
grid of `cols` columns. Each chart keeps its own title, grid, and series and
is scaled into an equal cell. The composed figure is a normal SVG, so it
saves to a file (`save_subplots_svg` / `save_subplots_html`) and opens in the
native window (`show_subplots_native`) just like a single chart.

```dn
sp1 = plot.line(xs, sines).title("sin").grid(4).minor_grid(2).size(380, 240);
sp2 = plot.line(xs, cosines).title("cos").grid(4).minor_grid(2).size(380, 240);
sp3 = plot.line(xs, damped).title("damped").grid(4).minor_grid(2).size(380, 240);
sp4 = plot.bar(buckets, envelope).title("bars").grid(4).size(380, 240);

// Compose into a 2-column grid...
figure = plot.subplots([sp1, sp2, sp3, sp4], 2);   // -> one SVG
plot.save_subplots_svg([sp1, sp2, sp3, sp4], 2, "grid.svg");
plot.show_subplots_native([sp1, sp2, sp3, sp4], 2); // ...or open it in the native window
```
